# WinQuad

一个类似安卓「大文件夹」的 Windows 桌面整理组件。

桌面上快捷方式太多、又舍不得删的话，可以拿这个把其中几个收进一个小格子里。
格子默认只占一个图标的位置，里面放四个程序，双击就启动，不弹面板。

它跟那种浮在桌面上的 Dock 不是一回事。它直接嵌进桌面图标层，和真图标待在同一层，
所以会被窗口正常盖住，按 `Win+D` 的时候还在那儿，不占任务栏，也不会出现在 `Alt+Tab` 里。

## v0.2 更新

- **每个格子可以有自己的占地和形状** —— 占几个桌面图标位（1×1、2×2……）、
  里面分几列几行（最多 8×8）。两层独立，所以可以「占 2×2 个图标位、里面放 3×3」
- **格子变大时图标和文字自动等比放大**，倍率取宽高里较小的那个，
  保证「一行正好放几个字」不变
- **空置的格子彻底透明**，不再顶着一块半透明底板
- **右键补齐快捷方式该有的操作** —— 打开文件位置、看属性（系统原生那个属性页）
- **文字效果可调** —— 新增投影，和描边可叠加；透明度参数改成滑条
- **修掉两个显示问题** —— 图标颜色失真（某些图标只剩一片白）、
  白色文字笔画末端的 ClearType 彩色花边

## 功能

- **嵌在桌面图标层里**，不是悬浮窗。会被窗口盖住，`Win+D` 时还在，不占任务栏、不进 `Alt+Tab`
- **双击即启动**，不弹面板
- 拖进去的 `.lnk` 自动追溯成真正的 `.exe` 再取图标，所以没有快捷方式小箭头
- `.url`（Steam 等商店在桌面上建的就是这个）同样支持：溯源成 `steam://rungameid/…`，
  桌面文件删掉也能启动；图标读它里面的 `IconFile`，不带小箭头
- 整块可以拖着走，松手吸附到桌面图标网格；目标位置被占了会自动让到最近的空位
- 位置按「第几列第几行」记，不是像素坐标，换分辨率不会跑偏
- 每个格子单独设占地（占几个图标位）、形状（里面分几列几行）、底色和透明度
- 管理器三栏布局，支持从资源管理器拖放添加；主界面和设置界面都有实时预览
- `config.json` 管全局，`group-*.json` 管每个格子。以 `_` 开头的是注释，可以直接
  把配置文件发给别人或 AI 帮忙改；管理器保存时注释和排版会保留（有回归测试守着）

## 下载哪一份

功能完全一样，区别只在运行依赖。

| | `WinQuad-v0.2.zip` | `WinQuad-v0.2-portable.zip` |
|---|---|---|
| 磁盘占用 | 约 840 KB | 约 93 MB |
| 要装别的东西吗 | 要，需要 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0) | 不用，解压就能跑 |

轻量版要装的运行时选 **".NET Desktop Runtime 10.x — Windows x64"**，
注意是 Desktop 那个，不是 ASP.NET 也不是 Console。

## 快速开始

详细操作看同目录的 `使用说明.txt`。三步：

1. 双击 `WinQuad.Manager.exe`
2. 底栏「参数设置」→「尺寸与图标网格」→ 点「读取当前图标间距」→ 确定
3. 回主界面点「保存并重启」

第二步别跳过。桌面图标间距每台机器可能不一样，不校准的话拖动吸附会不准。

## 轻量化

| 项目 | 实测 |
|---|---|
| 程序本体（轻量版，两个 exe + 依赖 + 配置） | 489 KB |
| 覆盖层内存 | 约 70 MB，其中 **程序自己约 4.7 MB**，其余是 .NET 运行时 |
| 后台进程 / 服务 / 驱动 / 安装程序 | 1 / 0 / 0 / 0 |
| 写注册表 | 只有可选的「开机自启」一项 |
| 写文件 | 只有自己目录下的 json 和两个日志 |

「程序自己约 4.7 MB」是实测的：编了个什么都不做的 WinForms 空窗口当基线，
它的私有工作集就有 8.7 MB，覆盖层 13.4 MB，减掉就是程序自己的部分。连续跑几小时也不涨。

图标提取、渲染、布局全走系统 API，没有引入任何第三方库。

这个项目全程由 AI 编写：用自然语言描述需求，AI 改代码，没有经过人工逐行评审。

功能都实测过，配置读写的回归测试也在仓库里（`--test-config` / `--test-save`）。
但内部实现未必规范，也没有做过安全审计。程序碰系统的操作只有两件：读写自己目录下的

用之前建议自己扫一遍毒，或者翻翻源码。

不保证长期维护。

## 文件说明

| 文件 | 作用 |
|---|---|
| `WinQuad.exe` | 桌面覆盖层本体（要带 `--overlay`，管理器会帮你做） |
| `WinQuad.Manager.exe` | 管理器，平时用这个 |
| `config.json` / `group-*.json` | 全局配置 / 每个四宫格的内容与占地形状 |
| `使用说明.txt` | 详细操作手册和常见问题 |
| `启动桌面四宫格.bat` / `编辑分组内容.bat` | 只叫出四宫格 / 打开配置目录 |
| `winquad.log` / `winquad-manager.log` | 运行后生成，报问题时带上 |

## 命令行

调试用，平时用不上。

| 命令 | 作用 |
|---|---|
| `WinQuad.exe --overlay` | 启动桌面覆盖层 |
| `WinQuad.exe --detect` | 实测当前桌面图标网格间距 |
| `WinQuad.Manager.exe --settings` | 只打开参数设置窗口 |
| `WinQuad.Manager.exe --test-config` / `--test-save <文件>` | 自检：保存后注释是否还在 |
