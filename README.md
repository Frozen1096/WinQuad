# WinQuad —— Windows 桌面四宫格

把桌面快捷方式收进 2×2 的小格子里，每个格子只占**一个**图标的位置。

> **WinQuad = Win + Quad**（Windows + 四格）
> 它不是一个悬浮窗，也不是一个 Dock —— 它把自己**嵌进 Windows 桌面图标层**，
> 所以它就在桌面上，被所有窗口盖住、露出壁纸时就在那儿，和真图标一样。

## 📦 你手上是哪一份？

本程序发布**两种打包**，功能完全相同，只是运行依赖不同。看一眼文件夹就能分辨：

| | **轻量版** | **便携版** |
|---|---|---|
| **怎么认** | 有一堆配套文件（`.dll`、`.deps.json`、`.runtimeconfig.json`） | 只有两个大 exe，没有别的程序文件 |
| **磁盘占用** | **约 490 KB** | **约 99 MB** |
| **需要先装东西吗** | 需要：**.NET 10 桌面运行时** | 不需要，解压即用 |
| **适合** | 自己机器、已装 .NET、在意体积 | 发给别人、不想让对方折腾环境 |

### 轻量版要装的那个运行时

去 <https://dotnet.microsoft.com/download/dotnet/10.0> 下载
**".NET Desktop Runtime 10.x — Windows x64"**（注意是 *Desktop*，不是 *ASP.NET* 也不是 *Console*），
装完双击 `WinQuad.Manager.exe` 即可。

没装的话双击会弹一个英文错误框，提示缺少 `Microsoft.WindowsDesktop.App`，那就是这个原因。

> 为什么轻量版能这么小：.NET 的运行时是多个程序共享的，程序本身只有 160 KB 左右。
> 便携版是把整个运行时塞进了 exe 里，所以体积翻了几百倍 —— 换来的是"零依赖"。

## ✨ 功能

### 桌面四宫格（核心）

- **嵌进桌面**：不是悬浮窗。它和桌面图标在同一层，被所有窗口盖住，
  按 `Win+D` 显示桌面时它就在那儿，不占任务栏、不出现在 `Alt+Tab`。
- **双击启动**：格子里的小图标双击直接启动对应的程序。
- **无快捷方式箭头**：拖进去的 `.lnk` 会被自动追溯成真正的 `.exe` 再提取图标，
  所以没有那个小箭头。
- **拖动吸附**：整块格子可以拖着走，松手自动对齐到桌面图标网格，和真图标一样逐格吸附。
  拖动把手是**最外圈的细环**，内部是启动区，两者不重叠，所以拖的时候不会误启动。
- **自动避让**：目标位置被别的桌面图标占了，会自动挪到最近的空格位；
  桌面上被格子盖住的位置**有视觉反馈**，不会悄悄压住图标。
- **位置按格位记录**：存的是"第几列第几行"而不是像素坐标，换分辨率、换显示器都不会跑偏。

> ### ⚠️ 关于图标缩小后看不清的问题
>
> 四宫格里每个格子只有 37×48 像素，图标会被缩到 **24×24** —— 也就是原始尺寸的一小部分。
> 这对图标本身的设计是个考验：
>
> - **设计简洁、主体明确的图标**（比如大多数工具软件）缩小后依然认得出来。
> - **细节多、文字多、靠颜色区分**的图标缩小后会糊成一团，几个格子看起来都差不多，
>   反而比原来更难找。
> - 格子里的**文字标签也会被截断**：7pt 字号下最多三个汉字，长名字只能显示省略号。
>
> **强烈建议：如果缩小后观感有问题、认不出来，请自行重绘一版"小尺寸专用"图标。**
> 做法很简单 —— 把图标换成一个主体突出、没有细节的简化版（纯色块 + 一个大字母也行），
> 在管理器里把「图标」那一栏填成你重绘的 `.ico` / `.png` 路径即可，不用动原程序。
>
> 也可以换个思路：**把「图标边长」调大、把「文字区高度」调小**，
> 或者干脆把四个格子换成不容易混淆的四个程序。参数改了立刻能在「实时预览」里看到效果。

### 管理器（图形界面）

- 三栏布局：左边管四宫格、中间管格子内容、右边管单个程序的外观与位置。
- **拖放添加**：直接从资源管理器把快捷方式或 exe 拖进管理器就行，支持多选。
- **实时预览**：设置界面顶部就是当前参数下的真实渲染效果，改一个数字立刻能看到。
- **参数自检**：实时提示参数有没有超限（比如图标+文字高度超过格子高度就会报红），
  不用等保存重启才发现问题。
- **快捷方式自动追溯**：`.lnk` → 真正的 exe，所以把桌面快捷方式删掉也不影响格子启动。

### 配置

- 两份 json 分工明确：`config.json` 管全局（尺寸/配色/字体/行为），`group-*.json` 管每个格子放什么。
- **注释写在 json 里**：以 `_` 开头的字段就是注释，程序会忽略。
  所以你可以直接把配置文件发给别人或丢给 AI 让它帮你改，不用担心看不懂。
- **保存不会丢注释**：管理器改配置时是"就地替换数值"，注释和排版原样保留（有回归测试守着）。

## 🪶 轻量化

**磁盘上确实很轻，内存上不算轻** —— 两个数字都摆出来，你可以自己判断：

| 项目 | 实测值 |
|---|---|
| 程序本体（轻量版） | **489 KB**（两个 exe + 配置） |
| 整个文件夹（含说明文档） | **509 KB** |
| 便携版两个 exe | 98.5 MB（把 .NET 运行时打了进去） |
| **覆盖层常驻内存** | **约 79 MB 工作集 / 72 MB 私有** |
| 管理器内存 | 约 128 MB（**只在你要改配置时才开**，平时关掉） |
| 后台进程 | **1 个** |
| 服务 / 驱动 | **0** |
| 安装程序 | **无**，解压即用，整个文件夹可以随便挪 |
| 写注册表 | 只有可选的**开机自启一项**，关掉即删 |
| 写文件 | 只有自己目录下的 json 和两个日志 |

> **关于那 79 MB**：这不是程序自己吃掉的，是 .NET 桌面运行时的内存基线 ——
> 一个几乎什么都不做的 WinForms 空窗口也要占几十 MB。程序本身的数据结构很小。
> 如果你对内存敏感，这一点要提前知道；**在意的话建议自己实测一下再决定**。
> 相比之下它真正省的是：没有后台服务、没有常驻索引、没有数据库、开机只起一个进程。

技术上它轻，是因为**它没有重新实现一个桌面**：

- 不做 Dock、不做小组件、不做搜索、不做文件索引，只做"把四个图标收成一个"这一件事。
- 不常驻后台服务，覆盖层本身就是几个挂在桌面上的子窗口。
- 图标提取、渲染、布局全部走系统 API（`ExtractIconEx`、GDI+、Win32 窗口区域），
  **没有引入任何第三方库** —— 这是它能保持 489 KB 的主要原因。
- 配置是纯 json，没有数据库、没有缓存目录。

## 🚀 快速开始

详细操作见同目录的 **`使用说明.txt`**。三步上手：

1. 双击 `WinQuad.Manager.exe`
2. 底栏 →「参数设置」→「尺寸与图标网格」→ 点 **「读取当前图标间距」** → 确定
   （★ 最重要的一步：桌面图标间距每台机器可能不同，不校准拖动吸附会不准）
3. 回主界面点「保存并重启」

想开机自动出现：勾上底栏的「开机自动启动」，再点「保存并重启」。
